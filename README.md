# Statistical Learning for Music Genre Analysis

Can statistical learning distinguish music genres using acoustic features?

This repository contains a university project developed for a Computational Statistics course.
The goal of the project is to evaluate whether quantitative acoustic features can effectively
distinguish between different music genres.

An original dataset was built by collecting music track data from the Spotify Web API and the
ReccoBeats API. After data cleaning and standardization, both unsupervised and supervised
statistical learning methods were applied.

## Contents
- `report/`: full project report (PDF)
- `src/`: R script used for data processing, modeling and validation
- `slides/`: informal presentation slides 

## Methods
- Data collection via APIs
- Feature standardization and PCA
- Model-based clustering using Gaussian Mixture Models
- Supervised classification with Gaussian models
- Monte Carlo cross-validation
